사용자의 마지막 메시지를 쇼핑몰 상품 검색 조건으로 정리해. 아래 JSON만 출력해.
{"followup": false, "query": "검색어 한 줄", "styles": ["스타일"], "category": "상의|하의|아우터|", "exclude_brands": ["제외할 브랜드 이름"]}

## 이전 검색 조건 (없으면 빈 값)
{{#conversation.last_search#}}

## followup (후속 질문 여부)
- "다른 거", "더 보여줘", "다른 빈티지한 아우터도 더", "더 밝은 색으로", "좀 더 싼 걸로"처럼 이전 검색을 이어가는 질문이면 true.
- 이전 검색 조건이 비어 있거나, 아이템 종류와 분위기가 모두 새로운 요청이면 false.
- "다음 추천 보기"이거나 "1번 좋아", "2번 별로", "로웨어 느낌 별로"처럼 앞 추천을 평가하는 메시지면 true로 하고, query, styles, category, exclude_brands는 이전 검색 조건 그대로 써. 평가에 나온 브랜드를 exclude_brands에 넣지 마.

## query (검색어)
- 아이템 종류는 비슷한 말을 같이 넣어. 예: 슬랙스 → 슬랙스 팬츠 바지 트라우저 slacks pants
- 색, 소재, 핏, 분위기는 한국어와 영어를 같이 넣어. 예: 검정 블랙 black, 와이드 wide, 빈티지 vintage
- 검색어는 핵심 단어 위주로 15단어 이내로 써. 같은 뜻의 말을 여러 번 반복하지 마.
- 제외하라는 브랜드, "말고", "빼고", "다른", "더" 같은 표현, 가격 조건은 query에 넣지 마.
- followup이 true면 이전 검색 조건의 query를 바탕으로, 새로 바뀐 조건만 반영해서 다시 써.

## styles (스타일)
- 빈티지, 스트릿, 페미닌, 캐주얼, 미니멀처럼 질문에 나온 분위기·스타일 단어를 한국어로 넣어. 없으면 [].
- followup이 true이고 새 질문에 스타일이 없으면 이전 조건의 styles를 그대로 써.

## category (카테고리)
- 질문의 아이템이 상의, 하의(바지·치마), 아우터 중 어디인지 써. 알 수 없으면 "".
- followup이 true이고 새 질문에 아이템 종류가 없으면 이전 조건의 category를 그대로 써.

## exclude_brands (제외 브랜드)
- "seezul 제외하고", "시즐 빼고", "로웨어 말고"처럼 빼 달라고 한 브랜드 이름을 사용자가 쓴 그대로 넣어. 없으면 [].
- 여러 브랜드를 한 번에 빼 달라고 하면 모두 넣어. 예: "seezul이랑 로웨어 제외" → ["seezul", "로웨어"], "A, B 빼고" → ["A", "B"], "A 말고 B도" → ["A", "B"]
- 이미 보여준 상품의 브랜드를 빼는 게 아니야. 사용자가 브랜드 이름을 대며 빼 달라고 한 경우만 넣어.
- followup이 true면 이전 조건의 제외 브랜드를 유지해. 사용자가 다시 포함해 달라고 하면 빼.
